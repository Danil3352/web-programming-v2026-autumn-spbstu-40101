# Лабораторная работа 2

## Задание

Вариант 2.

Реализовать функцию `toRoman(num)`, преобразующую целое число в римскую запись.

Поддерживаемый диапазон значений — до 3999.

## Реализация

Функция `toRoman` экспортируется как именованный ES module export.

Преобразование выполняется последовательным подбором римских обозначений от
наибольшего значения к наименьшему. Алгоритм учитывает стандартные вычитательные
формы римской записи, такие как `IV`, `IX`, `XL`, `XC`, `CD` и `CM`.

## Запуск

Импортировать именованный export `toRoman` из файла `solution.js` как ES module.
