# Лабораторная работа 1

## Задание

Вариант 2.

Создать компонент «хлебные крошки».

Требования:

- основа структуры — список;
- элементы списка — ссылки;
- последний элемент списка — `span`;
- цвет ссылок — `#0056ff`;
- ссылка при наведении подчёркивается;
- цвет `span` — `#333`;
- разделители между элементами реализованы с помощью псевдоэлемента `::after`.

## Реализация

Навигация содержит список элементов. Предыдущие уровни навигации представлены
ссылками, а текущая страница — элементом `span`.

Для горизонтального расположения элементов используется Flexbox. Разделители
между элементами создаются CSS-псевдоэлементом `::after`.

## Запуск

Открыть файл `index.html` в браузере.
